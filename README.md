# 📐 Olympiad

A personal collection of **mathematics olympiad** materials — covering problem sets, detailed solutions, lecture notes, coaching slides, mock exams, and reference books. Primarily focused on Indonesian national and university-level math competitions.

## 📝 About

This repository serves as a centralized archive for all olympiad-related work, including:

- **Problem sets & solutions** — Original and curated problems with full, rigorous solutions written in LaTeX.
- **Lecture & training notes** — Structured teaching materials used for olympiad coaching sessions, covering topics from introductory to advanced levels.
- **Mock exams (simulations)** — Timed practice exams that simulate real competition formats, complete with answer keys.
- **Past competition archives** — Collected past papers from various math competitions for study and reference.
- **Reference books & problem banks** — Curated textbooks and problem collections across all major subjects.

## 📚 Subjects Covered

- **Abstract Algebra** — Groups, subgroups, homomorphisms, ideals, quotient rings, symmetric groups
- **Real Analysis** — Sequences, convergence, continuity, differentiation, integration, inequalities
- **Linear Algebra** — Vector spaces, linear transformations, eigenvalues, rank–nullity theorem
- **Complex Analysis** — Analytic functions, roots of unity, complex modulus, contour methods
- **Combinatorics** — Counting principles, binomial identities, bijective proofs, inclusion–exclusion

## 🏆 Competitions Covered

| Competition | Level |
|---|---|
| **ONMIPA** | National university-level math olympiad |
| **OSITS** | Institut Teknologi Sepuluh Nopember science olympiad |
| **OSN / OSN-K** | National science olympiad for high school (district level) |
| **KSM** | Kompetisi Sains Madrasah (Islamic school science competition) |
| **UGM Internal** | Universitas Gadjah Mada internal team selection |

## 🛠️ Built With

All documents are typeset in **LaTeX** using standard mathematical packages (`amsmath`, `amssymb`, `tikz`, `beamer`, etc.).

### How to Compile

1. Clone the repository:
   ```bash
   git clone https://github.com/TetewHeroez/Olympiad.git
   ```
2. Open any `.tex` file in your preferred LaTeX editor (e.g., VS Code with LaTeX Workshop, TeXStudio, or Overleaf).
3. Compile with `pdflatex` or `xelatex` to generate PDF output.
